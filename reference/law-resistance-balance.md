# 苦难律法抗性与经济调整

- 元素庇护 I / II：敌人受到的魔力、火、雷、圣伤害减少 10% / 累计 20%，物理伤害不变。
- 异常耐性 I / II：敌人的中毒、猩红腐败、出血、冻伤、睡眠、发狂、死亡触发阈值提高 15% / 累计 30%。使用耐性倍率，不修改原有免疫设置。
- 贫瘠 I / II：击杀和战斗奖励卢恩从 -25% / -50% 调整为 -15% / -30%。
- 奸商 I / II：商店涨价从 +30% / +60% 调整为 +15% / +30%。奖励二选一保持不变。

新抗性节点各 10 分，编号追加到 27–30，旧节点编号与旧律法码保留。包含最高位新节点的律法码扩展至 8 位。敌人效果仍由房主施加。

联机协议更新为 37 / TCP 22，全队需使用同版 DLL 与 regulation.bin。构建器 law-patch 支持从旧参数升级，并核验所有非律法参数保持不变。需要更新 DLL 和 regulation.bin，只有代码更新不会改变游戏内参数。
