# 商人挑战与铃珠

仅商店里的商人可被击倒，其他服务 NPC 保持保护。商人倒下后关闭交互和出口，启用店内已有的铃珠猎人实体；加载完成后等待五秒开战。击败猎人后可通过出口继续，本间商店不恢复商人。

每间店最多触发一次；每次随机获得武器、防具、护符铃珠中的一种，作为背包物品显示。数量以本局存档为准，不能通过丢弃、转交或跨局携带增加效果。同类可叠加，每颗从下一次进商店起追加五件对应商品。当前店的已购库存不刷新。新局清零。

联机需全队仍在当前商店；任一玩家击倒商人后，由房主观察同步后的死亡状态并发起挑战。全体存活玩家绑定猎人后开战，房主确认击杀，全队获得同一种铃珠。观战玩家也结算并沿用胜利复活逻辑。已经有队员离开时不再发起挑战，避免把队员卡在不同节点。
