# HansFix3 源码修复移植

来源：用户提供的 `ErdtreeTower-Overlay-HansFix3-on-832688a/HansFix3-source.patch` 与 `source-patches/`，作者署名 Hans。按其声明沿用项目 GPL-3.0-or-later 及附加条款。旧 DLL、preview.me3、协议号 33 及 modified-build 身份标记未移入；当前协议为 36 / TCP 21。

已移植：同一事件房间的守卫战由全队共享一次；攻击禁用状态恢复；停用凯丹佣兵和雪原山妖的随机抽取但保留实体编号；场边引导者延迟生成及禁用诊断开关；旧旅程无法加入队伍时重开大赐福菜单；空闲大赐福内的队友故障重握手；通过系统导出地址挂接 SetCursorPos。

适配与收紧：

- 保留当前 DLC 池、坠星成兽调整、联机苦难律法、地图划线及事件跳过修复。
- 守卫共享完成后剔除等待中的守卫请求，并重排尚未开始的波次，防止后续甲虫事件因波次跳号被拒绝；同步更新重试记录。
- 攻击锁在每次 tick 返回后统一同步，覆盖提前返回路径。
- 引导者需连续站稳 3 秒，离地或读图会重新计时。
- 原补丁的“剩余满血敌人 60 秒判胜”不是可靠异常判据，默认关闭。仅显式设置 `ERDTREE_TOWER_STALL_VICTORY=1` 时允许单人或房主执行，用于诊断。
- `Launch-Seamless-NoAttendant.ps1` / `Start-Seamless-NoAttendant.cmd` 适配本项目启动器，只禁用场边引导者，不开启自动判胜。

原包对竞技场闪退原因的描述属于提供方诊断，不视为当前环境已复现或已根治。此包没有中文字体修复。
