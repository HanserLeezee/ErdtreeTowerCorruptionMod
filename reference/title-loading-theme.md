# 主菜单与加载页主题

首版使用原创几何矢量插画：灰绿高塔、金色树冠、旧纸色面板。没有使用《杀戮尖塔》的原始素材。

编辑 `scene-builder/title_theme.json` 可修改标题、副标题、标语、配色和轮换提示。背景构图由 `title_theme.py` 的 `artwork` 生成，设计预览与游戏矢量使用同一组绘制指令。配置是构建输入，不是运行时热加载；修改后须重新生成 GFX。

```powershell
python scene-builder/title_theme.py --original <原版menu目录> --output <新的输出目录> --ffdec <ffdec.jar> --java <java.exe>
```

输出 `menu/` 中四个文件分别覆盖主菜单、独立标题 Logo、普通加载页和简化加载页。仅重编对应 ActionScript，校验原时间轴、其他标签及无关脚本保持不变。主菜单沿用原功能按钮，调整容器位置；加载页保留原进度控件，提示按 30 FPS 帧计时每 8 秒切换，不使用此前在游戏中报错的 getTimer。

加载页插画置于原黑底之上、原加载图标／进度控件之下。主题绘制不接收鼠标事件。移除这四个新增 GFX 覆盖文件可恢复原版，不涉及已有武器词条／Boss 字体效果文件。

PNG 为设计预览，主菜单按钮文案为示意，不能冒充游戏截图。当前仅通过离线编译及结构校验，中文字体、原生按钮定位、淡入淡出、两种加载页层级和不同分辨率的游戏实际效果仍待实测。
