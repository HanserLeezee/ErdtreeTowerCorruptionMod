# -mod-
堕落模式（HansFix） 补丁 — 基于爬塔启动器 1.1.2 / 模组 v99（补丁版本 r8）

【r8 改动】
- 「向下次数」改名为「堕落值」；进入下一幕时只继承上一幕结束时堕落值的一半（向下取整）。
- 修复堕落装备变多以后，领完奖励或进入堕落商店时卡顿 1–2 秒的问题（游戏内文字改写太慢）。
- 堕落装备说明里不再附加“红色关卡奖励：……”的备注。

【r7 修复】
- 在红篝火选回走过的商店（或其他非战斗关卡）开启堕落挑战时，地图重排把这个关卡变成了战斗关，
  但游戏已经把你送进了商店房间：商店里没有堕落装备，传送门无法交互而卡死。
  现在选中的那个关卡保持地图上原来的类型（选商店就是堕落商店），房间和货物也按开启挑战后的地图生成。
- 夜晚：r5/r6 只发了“改时间”的请求，游戏时间实际一直停在早上 7 点；现在直接改写当前时间。
  日志里会记 HANSFIX_NIGHT set 22:00。如果日志有这一行但天空仍是白天，说明那张房间地图的光照是固定的。

【功能】
第一幕开局的地图右侧有「堕落：关/开」按钮。开启后可以沿连线向上或向下进入相邻且没去过的关卡；
整局（包括后续幕）保持堕落模式，打到首领即过幕。

【向下】
- 沿连线向上走和原版一样；其他方向（原版不允许的方向）算一次“向下”。
- 地图上可以向下进入的关卡用红色高亮（原版是黄色），走过的向下关卡也保持红色；
  堕落开关下方显示“堕落值”（本幕的向下次数 + 上一幕继承的一半）。篝火、事件等没有敌人的关卡也照样计数。
- 第 k 次向下的战斗关卡，敌人血量 ×2×1.1^(k-1)、攻击伤害 ×(1+0.05k)
  （血量：第一次 2 倍，第二次 2.2 倍……；伤害：每次向下 +5%，第一次 1.05 倍，第 20 次 2 倍；第 60 次之后不再增长）。
  联机时由房主施加，和原版的逐层强化叠加。
- 打完红色战斗关卡（杀完所有敌人）进入和精英关卡相同的结算界面，选项数量随向下次数增加：
  第 1–3 次向下 1 个，4–6 次 2 个，7–9 次 3 个，10 次起 4 个
  （依次是：精英装备、额外一件、护符效果、圣杯滴露/余烬；额外一件的奖励池包含全部魔法与祷告，
  按职业能用的来抽——原版里只有星辉术士类职业拿得到魔法、祷誓者类职业拿得到祷告）。
- 奖励里带随机词条的武器和防具会“堕落”：随机一个词条数值 ×2、另一个词条数值 ×(-1)；
  只有一个词条的装备随机 ×2 或 ×(-1)。名字前加“堕落的”，例如：堕落的史诗·智力/信仰·大龙爪。
  爬塔界面里名字带暗红色描边、词条说明为浅红色；背包里检视这件装备时，名字和词条也会同步改写，
  词条为浅红色，名字颜色不变（游戏自带的文字不支持描边，所以背包里只有“堕落的”前缀）。
- 没有敌人的红色关卡（篝火、商店、事件、宝箱）照常使用，没有额外的红色奖励。
- “防御时精力消耗”这个词条在游戏里是护符的固定效果、没有数值可改，所以不会被改动。
- 背包文字是在游戏内存里临时改写的：回到大赐福、换局后恢复原样；
  日志里有 HANSFIX_CURSE ... texts=数字，数字为 0 说明这一步没成功（请把日志发给我）。

【堕落挑战（r5 新增）】
- 本模式改名：游龙模式 → 堕落模式（开关文件名仍是 hansfix-wander.enabled）。
- 每一幕首领下面那一排全是篝火，其中一个是红篝火。
- 起点那排四个怪物关卡的下方、地图下缘之外，有一个“堕落的首领”（首领图标上下翻转）。
  平时是灰白色，可以看见但不能点击、不能传送。
- 在红篝火选下一关时，选一个相邻、已经走过的关卡，就会开启【堕落挑战】：
  走过的关卡全部清空，除起点、篝火与首领外的关卡类型重新随机，之后只能向下走；
  堕落首领被点亮，一路向下走到底挑战它，打赢即通过本幕。
- 红篝火与堕落挑战中，游戏时间会被推到夜晚（与赐福点“消磨时间”同一个功能），离开后推回白天。
  部分竞技场的光照可能不随时间变化。
- 堕落首领与本幕首领不同，强度按当时的向下次数叠层。打赢后会出现两次奖励页面，
  每页三件“三个词条中两个 ×2、一个 ×(−2)”的传说武器或防具，可以各选一件。
- 堕落商店（向下进入的商店；堕落挑战里的商店都是）：所有带词条的武器、防具都是“堕落的”
  （一个词条 ×2、一个 ×(−1)，在商店里就能看到改动后的说明），整体价格上涨 25%；
  在同一家堕落商店累计消费满 3 万卢恩，送一件“两个 ×2、一个 ×(−2)”的传说装备（每家一次）。
- r4 及更早开始的旅程可以继续玩，但那一局不会出现红篝火和堕落首领。

【联机】
堕落模式会改变联机协议（协议号 +1000）。无缝联机时队伍里所有人都必须装同一个堕落模式补丁，
否则握手时会提示“爬塔协议版本不匹配”。房主开关堕落，队员自动跟随；每人奖励里的堕落装备各自独立。

【这个补丁会替换 regulation.bin】
向下强化和扭曲词条需要新的游戏效果，所以本补丁带了 scene-assets/regulation.bin：
它是官方 v99 的 regulation 加上 330 条新效果（300 条堕落模式 + 30 条新誓约，与新誓约补丁是同一个文件），没有改动任何已有内容。
只装堕落模式时，新誓约的效果不会被用到；誓约仍是官方的十种、每幕两选一。

【联机修复与通用改动（两个补丁都包含）】
- 地图画线区域放大：覆盖整张路线图和下缘之外的区域。
- 史东薇尔跑城、战车等挑战房间：有队友完成挑战时，已经倒下的队员会在原地自动复活，再一起回到选关地图
  （不会再出现死亡玩家无法选关、按钮半透明）。需要无缝联机 2.0.1 / 2.0.2 的复活功能，日志里有 PARTY_REVIVE。
- 地图补丁：修复按 N 打开只读地图后一闪就关的问题。
- 商店：打开商店时日志会记一行 SHOP_VIEW，若仍看到剩余 0，请截图并把 tower-preview.log 发来。

【适用版本】
爬塔启动器 1.1.2 安装的官方模组 v99（启动器里显示的模组版本 1.1.1）；单人与无缝联机 2.0.1 / 2.0.2 均可。
怎么确认：模组目录里的 preview.me3 写的是 path = 'erdtree_tower_preview_v99.dll'，
tower-install.json 开头是 {"version":99。两样都对上再装。

【安装】
1. 先在启动器里把模组更新到最新，关掉游戏。
2. 打开爬塔模组目录（里面有 erdtree_tower_preview_v99.dll、preview.me3、scene-assets 文件夹的那个目录）。
3. 把压缩包里的文件解压进去，提示同名文件时选择“替换”。
4. 用启动器正常开始游戏即可。
（之前装 v98 补丁时留下的 erdtree_tower_preview_v95.dll 已经不会被加载，可以删掉。）

【和其他补丁一起用】
所有 HansFix 补丁里的 DLL 是同一个文件，每个补丁只多带一个自己的开关文件（hansfix-*.enabled）。
堕落模式、更好的地图与商人、新誓约三个补丁可以任意组合安装，先后顺序无所谓，互不依赖
（堕落模式和新誓约带的 regulation.bin 是同一个文件，两个都装也没问题）。

【卸载 / 恢复官方】
- 只关某个功能：删掉对应的 hansfix-*.enabled 文件。
- 新誓约和堕落模式带的 regulation.bin 在两个补丁都删掉开关后可以留着，不影响官方内容；想彻底还原就用下面的校验修复。
- 完全恢复：启动器「设置 → 更新 → 校验并修复文件」，官方文件会被还原（开关文件留着也没影响）。

【注意】
- 启动器更新模组或“校验并修复文件”后，补丁文件会被换回官方版，需要重新解压一次本补丁。
- 模组更新到 v99 之后的版本时，请等对应新版本的补丁；万一装错，补丁会自动关闭全部功能，
  并在屏幕左上角提示你修复文件。
- tower-options.ini 不存在是正常的（启动器只在你改过设置时才写），不影响补丁。
- 日志 tower-preview.log 里有一行 HANSFIX，可以确认补丁是否生效，例如：
  HANSFIX wander=false better_map_merchant=true oaths=false map_key=N protocol=37
  如果日志里找不到 HANSFIX 这一行，说明游戏加载的不是补丁 DLL（多半是 DLL 名字和 preview.me3 对不上）。
