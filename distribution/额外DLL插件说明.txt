额外 DLL 插件

推荐用启动器：设置 → 插件 → 「添加 DLL…」或「添加插件文件夹…」。
插件会复制进模组目录的 plugins 文件夹，单人和无缝联机都会加载，下次启动游戏生效。
列表里可以随时关掉或移除；模组更新不会覆盖、也不会删除 plugins 文件夹。

- 添加 DLL：连同同名的配置文件（如 xxx.ini）和同名文件夹一起复制。
- 添加插件文件夹：整个文件夹复制，顶层的每个 DLL 都会登记；只是辅助用、不需要加载的 DLL 在列表里关掉。
- 不能添加 ersc.dll、dinput8.dll、me3 或爬塔自己的 DLL。

不用启动器时，手动编辑 plugins\natives.toml（没有就新建），格式同 ME3：

[[natives]]
path = 'plugins/xxx/xxx.dll'
enabled = true

path 可以写相对模组目录的路径，也可以写完整路径（建议用正斜杠，不能含单引号）；
enabled = false 表示停用；load_after 等选项按插件作者的 ME3 说明添加，启动器开关时会原样保留。
文件不存在的插件启动时会跳过并给出提示，不会拦住游戏启动。

单人模式启动时会在模组目录生成 preview.launch.me3（随包的 preview.me3 加上插件），不要编辑这个临时文件。

旧方式仍然有效（只对无缝联机）：seamless-entry/runtime/custom-natives.toml 与 seamless.me3。
同一个 DLL 在多处配置时只加载一次。
此功能只提供加载入口，不保证第三方插件与无缝、爬塔之间的兼容性。插件是第三方程序，只添加你信任的来源。
